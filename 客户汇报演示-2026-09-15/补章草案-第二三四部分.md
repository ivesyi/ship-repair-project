## 一、源站是什么

这是我们**原始客户版**的线上部署（标题一致：「智能体技术与船舶维修应用方案 · 汇报」）。它的章节表正好就是封面承诺的四段式：

| # | 章节 id | 标题 | 页数 | 旁白数组 |
|---|---|---|---|---|
| ① | `agent` | 认识智能体 | 7 | `D1` |
| ② | `manufacturing` | 智能体在制造业的应用 | 4 | `x1` |
| ③ | `case` | 船舶维修应用方案 | 11 | `U1` |
| ④ | `deployment` | 硬件部署与实施 | 5 | `p1` |

合计 27 页，外加封面 1 页。

**最重要的好消息：这 27 页不写在一个个独立组件里，而全部由同一个通用渲染器出画面。**

```js
function gl({kind, title, note, data, tag, page}) { ... }
```

`data` 是 `|` 分隔的字符串，`kind` 决定版式，共 15 种：

| kind | 画面形态 | kind | 画面形态 |
|---|---|---|---|
| `cover` | 封面 | `arch` | 架构分层图 |
| `flow` | 横向流程步骤 | `source` | 原件扫描页 + 高亮行 |
| `points` | 编号要点列表 | `equation` | 算式大字 |
| `grid` | 卡片网格 | `area` | 面积变化对比 |
| `table` | 表格 | `shots` | 实机截图组 |
| `compare` | 左右对比（能/不能） | `video` | 视频播放器 |
| `loop` | 闭环循环图 | `sop` | 七步流程 + 跳转按钮 |
| `network` | 局域网拓扑图 | `ten` | 10 份文件 + 第 11 份验证 |

**结论：搬过来主要是搬「通用渲染器 `gl` + 它的 121 条 `vs-*` 样式 + 各章的数据数组」，不是搬 27 个页面。** 工作量集中在主题适配，不在重画。

## 五、主题适配清单（「改成适配现有蓝白主题」到底要改什么）

源站是**藏青主题**，我们是**亮蓝主题**。好消息是 `vs-*` 样式全部走 CSS 变量，所以只要把变量接上，颜色就自动跟着变。

### 1. 三个变量缺失，必须补

| 变量 | 源站值 | 我们的处理建议 |
|---|---|---|
| `--primary` | `#1b3a5c` 藏青 | **→ `#4361ee`**（直接等于我们的 `--accent`，这样新页和现有页同色） |
| `--accent-2` | `#c2410c` 砖橙 | 语义是「风险／边界／待办」（用在「不替代什么」「待完成」「硬约束」）。建议**保留暖橙**，蓝橙是对比色、不破坏蓝白基调 → `#c2410c`；若要绝对单色蓝白，可换成 `#1b3a5c` |
| `--accent-2-soft` | `rgba(194,65,12,.08)` | 跟随上面的选择给对应的 8% 透明版 |

### 2. 一处硬编码色必须改

`.vs-cover-grid` 的封面网格底纹写死了 `rgba(27,58,92,.05)`（藏青）。要换成蓝色版：`rgba(67,97,238,.05)`。

其余硬编码只有 `#000` 和 `#fff`，属于通用中性色，不用动。

### 3. 内边距要统一

源站 `.vs-scene` 自带 `padding:60px 96px 70px`，我们现在统一用 `var(--stage-pad-y) var(--stage-pad-x)`（80px / 110px）。**建议改成 padding 变量**，否则新页的文字比现有页贴边，切换时会有肉眼可见的跳动。

### 4. 字体与圆角天然兼容

- `vs-*` 只用了 `var(--font-body)` 和 `var(--font-mono)`，会直接继承我们的 `Manrope/Inter + Noto Sans SC` 与 `JetBrains Mono`。
- `vs-*` 里**没有任何 `border-radius` 和 `box-shadow`**，全是直角平面——和我们现有主题（`--r-stage:0`、平面无阴影）一致，不用改。

### 5. 章节轨（底部进度条）建议对齐四段式

现在轨上是 7 格（`01 封面 … 07 三种开法`），和封面的「四个部分」对不上。建议**在章节注册表里把现有章节按四段式归组**（技术上是加一层按 step 范围分派的壳组件，改动可控）：

```
01 封面
02 认识智能体            ← 现有「五个痛点」+「从功能到对话到智能体」+「六阶段模型」
03 智能体在制造业的应用   ← 新增
04 船舶维修应用方案       ← 现有「任务循环图」+「发动机与整车」+「三种开法」+ 新增案例线
05 硬件部署与实施         ← 新增
```
