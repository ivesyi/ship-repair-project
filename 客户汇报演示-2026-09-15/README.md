# 客户汇报演示（2026-09-15）

面向客户的「智能体技术与船舶维修应用方案」汇报演示，蓝白主题，离线单文件版。

- **打开**：双击 `index.html`（详见《使用说明.md》）
- **讲稿**：《现场讲稿.md》，68 页口播全文，页码与演示步骤一一对应
- **结构**：按封面承诺的四段式 —— ① 认识智能体（P2–P41，六个章节）→ ② 制造业中的应用（P42–P45）→ ③ 船舶维修应用方案（P46–P61，含三种开法）→ ④ 硬件部署与实施（P62–P68），共 68 页、十个章节

## 技术来源

基于 [ivesyi/classes](https://github.com/ivesyi/classes) 课程三第 1 课课堂演示工程二次开发：保留原工程全部设计与动效，话术整体改写为客户视角。本目录为构建产物（Vite + vite-plugin-singlefile 生成的自包含单文件 + 图片目录），无需安装依赖、无需联网。
