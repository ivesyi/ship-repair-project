# 会议演示：一张手填维修单如何变成电子档案

## 一句话说明

经办人交来照片，Agent 转成电子草稿；人确认抄录，Agent 核算并列出疑点；人逐项说明，Agent 生成待正式审批的交付档案。

## 从头走一遍

1. 打开 Desktop 的“船舶工作台”，点击“用模拟手填单走一遍”，或选择单页图片后上传。示例为AI生成的模拟手填单，不是真实客户单据。
2. 自动识别期间观察状态。完成后左侧保留原图，右侧出现可编辑的船名、日期、原合计、三项明细和备注。模型估计的行区域只辅助定位，不承诺精确。
3. 对照原图确认抄录。若合计识别成“69166.00元”，只去掉数字字段的“元”；不要把原单6670.00元改成8280.00元。勾选确认，点击继续。
4. Agent 自动调用检查工具。展示70776.00元试算总额、1610.00元差额，以及块数与重量、历史价格适用性三项问题。
5. 先不填说明就尝试归档，确认被拦截。逐项填写演练依据；不确定时标记待补充，这会阻止归档。示例可以说明：保留原错误金额、试算单列；锌块按块计算，重量不替代块数；历史单价只用于演练，不作为现行报价。
6. 全部说明保存后点击生成交付档案。Agent 调用归档工具，完成后显示“待正式审批”。下载可离线打开、打印的网页档案，其中嵌入原图、电子明细、识别与人工修正、问题处理和过程记录。

## 分工与当前边界

图片识别和解释由已部署千问模型执行，核算与归档由程序工具执行，疑点确认由人执行。会话、工具调用与任务状态由 Harness 管理。当前模型通过 SSH 转发访问 AutoDL，尚未通过客户现场物理断网验收。

当前支持PNG、JPEG、WebP单页图片，不支持直接上传PDF、多页合并、现场语音或视频。此流程尚未接入真实知识库检索、生产技能发布或正式审批系统。填写说明仅表示问题处理范围已记录，不等于正式采购批准。
