# 工作流共创演示定位

我们提供 FDE 服务：进入客户现场，理解真实流程，联合客户专家把技术接入业务，并用真实任务验证改进。我们不以船舶维修行业专家的身份给出工艺标准或维修结论。

统一工作台保留两个案例：维修单上传与纠错、历史经验辅助方案编制。它们用于讨论哪些步骤耗时、哪里需要人判断、哪些数据与规则可供 Agent 使用。页面中的案例、价格和工艺系数均为模拟演练材料，不是客户业务标准。

客户负责业务经验、规则、权限与验收口径；我们负责数据接入、流程设计、工具开发、Agent 编排、离线部署和验证；双方用真实任务共同确认收益及适用边界。

会议顺序：先看现有工作怎么完成，再演示可以接入技术的位置，最后确认现场调研对象、代表性材料和小范围试点的验收指标。指标需建立客户现状基线，可包括处理耗时、遗漏率、人工修改量和结果可追溯程度，不提前承诺节省比例。

当前合并版采用同窗口两个常驻案例视图，切换不重建视图，保留填写内容和正在处理的状态。历史方案中的 Agent 主动推荐参照仍需继续完善，不将当前人工选择界面描述为已实现自动推荐。
