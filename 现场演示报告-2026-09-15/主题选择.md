# 主题选择

首推“电光企业”：适合会议室白底投影、企业方案讲解。备选“蓝图”偏工程图纸；“深霜”偏暗色演讲。中文使用对应中文字体，技术标识不进入主舞台。

## 完整可选主题

- **包豪斯**：净色底 + 主色蓝强调色 + Archivo Black 黑体. 包豪斯 / 布鲁塔利风格, 适合观点鲜明的演讲与产品发布. 适用：产品发布、观点宣言、设计演讲、品牌主张。
- **蓝图**：深藏青底 + 青色强调色 + IBM Plex Mono. 工程蓝图 / 工业图纸气质, 适合系统架构与技术拆解. 适用：技术架构、系统拆解、技术评测、工程教程、API / SDK 介绍。
- **焦点信号**：暗渐变底 + 大橙色焦点色卡 + Archivo Black / Space Grotesk 字体。签名：占位主角色卡 + 大编号制表数。适合 pitch deck、产品发布、宣言型章节。 适用：pitch deck / 投资人路演、产品发布 / 新品宣传、营销片头 / brand keynote、大字宣言 / 标题片、season hero / 主题营销。
- **粉笔花园**：深色石板底 + Patrick Hand 手写字体 + 粉笔黄强调色. 教室 / 课堂讲解风. 适用：科普讲解、教学课堂、知识分享、亲切口吻视频、面向初学者。
- **电压创意**：饱和电光蓝底 + 霓虹黄强调 + Syne 几何衬线 / Space Mono 等宽。签名：halftone 网点纹理（复古朋克工作室感）。适合设计周、创意工作室、视觉文化话题。 适用：设计周 / 创意分享、工作室作品集 / showcase、视觉文化 / 字体话题、音乐 / 艺术节预热、复古朋克 / 街头文化。
- **暗夜植物**：高级感暗底 + Cormorant 斜体衬线 + 暖陶 / 玫粉 / 鎏金叠层。签名：柔光晕染 (blurred light pool)。气质介于时尚刊物封面与博物馆图录之间。 适用：品牌故事 / 形象片、时尚 / 美妆、生活方式 / 旅行、文化 / 艺术评论、高端产品发布。
- **深霜**：克制的深色科技演讲主题。近黑藏青底 + 冰蓝单一高光，大字、大留白、慢速电影感揭示。无霓虹、无花哨渐变，冷静理性、工程气质。 适用：tech talk、keynote、AI 独立开发、research forum、product demo、深色科技演讲。
- **沙丘**：炭褐当墨 + 沙底，几乎不用 accent —— 克制、高级。Inter 显示 + Source Serif 正文。像建筑作品集、画廊手册、沙漠黄昏的色温。 适用：建筑 / 室内 / 空间、艺术展览 / 画廊手册、设计师 / 工作室作品集、时尚 / 高端品牌、审美优先的私享会。
- **电光企业**：净白底 + 单一电光蓝 + Manrope 全场。签名：贴底 4px 电蓝色块。企业感、清晰、自信，不冷漠，适合 B2B 与投资人场景。 适用：B2B 产品演讲、投资人 / 路演 deck、企业财报 / 季度更新、行业研究 / 趋势报告、企业咨询 / 培训。
- **森林墨**：深森林绿当墨（绿就是字色本身）+ 象牙暖纸。Source Serif 正文 + Playfair Display + Noto Serif SC。像旧版《国家地理》，沉稳、有呼吸感、克制。 适用：自然 / 可持续 / 环保、户外品牌 / 农业、纪录 / 非虚构、文化 / 行业观察、慢生活 / 文学农庄。
- **靛蓝瓷**：深靛蓝当墨（靛蓝就是字色本身，而非 accent）+ 瓷白纸。Playfair Display + Noto Serif SC + IBM Plex Sans。学术、有深度，像蓝印花瓷器或一本当代思想期刊。 适用：学术 / 研究 / 论文解读、AI / 数据 / 工程深度、中国当代文化、技术发布会 / 严肃汇报、思想型 / 评论型长文改编。
- **牛皮纸**：深棕当墨 + 牛皮米。像老笔记本或手戳信封：暖、有年代感、手作味。Fraunces + Noto Serif SC + Source Serif 正文 + 紫铜色 accent。 适用：书评 / 文学随笔、历史 / 怀旧 / 老物、独立杂志 / zine、手工艺 / 食物 / 农产品、慢生活 / 人文。
- **暗色印刷**：暖色暗底 + 单一热橙强调色。电影感、终端气质、开发者审美。 适用：开发者教程、AI / 工具评测、极客向产品介绍、技术 deep dive。
- **黑白印刷**：微暖白底 + 墨黑 serif + 单一墙墨蓝强调色. 高对比印刷杂志气质, Monocle / Wallpaper / MIT Press 那种沉静讲究. 适用：深度阅读改编、学术 / 思想型内容、品牌故事、高级感产品、文化 / 艺术评论。
- **霓虹赛博**：深海军底 + 电光青 + 玫红双霓虹 + Clash Display / Satoshi 字体。签名：青色发光网格 + 双色霓虹描边。赛博朋克未来派审美。 适用：AI / 大模型评测、web3 / 区块链、网络安全 / 黑客向、未来主义产品、赛博朋克 / 科幻话题。
- **报社**：报纸奶油底 + 墨黑 serif + 报头红强调色. 老派大报 / 纪录片气质, 像一篇 NYT 特稿. 适用：纪录片 / 报道、深度评测、时事评论、AI 产品分析、热点解读。
- **亮色印刷**：暖色奶油底 + 单一热橙强调色。杂志气质、柔和日间审美。 适用：杂志型内容、生活方式、日常工具评测、温和教程、面向大众的科技解读。
- **柔光梦**：柔粉蓝灰底 + 奶油卡 + 单一鼠尾草绿强调色 + Plus Jakarta Sans。签名：单边多色 pill 色条。友好但不腻，适合女性向 / 教学 / onboarding。 适用：产品 onboarding / 教程、友好教学 / 知识科普、女性向 / 生活方式、心理 / 健康 / 母婴、情绪向品牌片。
- **双拼画布**：双色画布：暖蜜桃 + 冷薰衣草作为成对底色 + Outfit 几何无衬线 + 玫红强调。签名：双调底色（左桃 / 右紫），适合做对照与对话型章节。 适用：双主题对比 / 辩论、故事讲述 / 对话、创意分享、轻量品牌片、概念对照型科普。
- **日落 Zine**：暖蜗色纸底 + 玫红强调色 + 厚体 Fraunces serif. 独立杂志 / 丝网印 zine 风, 俏皮有人情味. 适用：生活向 vlog、创意分享、趣味评测、小红书 / 抖音风、文化 / 表达型。
- **瑞士克莱因蓝**：瑞士国际主义风。**极细 200 weight** Inter / Helvetica + 净暖白底 + 克莱因蓝（IKB）单一锚点色。签名：1px 发丝网格 + 200 重字 hero 数字。Massimo Vignelli / Helvetica Forever 那种克制冷静。 适用：AI / 科技产品发布、年度总结 / 数据汇报、设计 / 工程领域分享、严肃学术 / 国际化品牌、信息驱动设计 / 信息图。
- **终端绿**：纯黑底 + 磷光绿强调色, 全程等宽字体. Matrix 黑客 / 80 年代终端感, 最适合技术演示与 CLI 教程. 适用：CLI 工具教程、黑客 / 安全话题、技术演示、命令行实操、复古技术致敬。
- **复古编辑**：奶油底 + 厚体 Fraunces 斜体 + 暖陶强调色，有性格、会说话。签名：细线几何叠层（圆 + 线 + 点）。介于杂志专栏与艺术评论之间，俏皮、自信、有声音。 适用：个人见解 / 评论、文化随笔 / 美学话题、有声音的博主、设计 / 字体话题、文艺类长文改编。
- **暖色 Keynote**：奶油纸底 + 单一青色强调色 + 舞台上的暖色网格. SaaS Keynote 与编辑器气质. 适用：SaaS 产品 keynote、B 端产品发布、工具产品讲解、团队对外汇报。
